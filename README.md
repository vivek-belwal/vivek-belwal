## 🚀 Projects

### 🧱 [BrickBreaker](https://github.com/vivek-belwal/BrickBreaker)
> A classic Brick Breaker game built with **vanilla HTML, CSS & JavaScript**.
- 🎮 Multiple levels & dynamic power-ups
- ⚡ Smooth ball physics & responsive paddle controls
- 🏆 Combo scoring system & sleek animated UI

---

### 🌤️ [SunTrack](https://github.com/vivek-belwal/SunTrack)
> A **live weather forecasting website** to check real-time weather of any city.
- 🌍 Search weather by city name
- 🌗 Light & Dark mode support

---

### 🫧 [BubbleShooter](https://github.com/vivek-belwal/BubbleShooter)
> A **neon-themed Bubble Shooter arcade game** built with React, TypeScript & Vite.
- ✨ Glowing bubbles & particle explosions
- 📱 Touch support & 60fps Canvas rendering
- 🎯 Multi-level progression — match 3+ bubbles to pop them!
